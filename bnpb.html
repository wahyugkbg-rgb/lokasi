Alat ini mencoba beberapa jalur koneksi (langsung, beberapa proxy CORS publik) satu per satu sampai salah satu berhasil, lalu mem-parsing tabel HTML-nya secara langsung di browser Anda.
ℹ️ Catatan cakupan data & log percobaan koneksi
Catatan jujur soal cakupan data: endpoint sumber ini mengabaikan parameter tanggal/jenis pada URL — ia selalu mengembalikan ~120 kejadian terbaru (jendela bergulir), difilter oleh JavaScript sisi-klien di situs aslinya, bukan API tanggal penuh. Karena tanggal hari ini masih dalam 2026, seluruh baris yang tampil praktis otomatis "tahun 2026" — tapi ini bukan arsip penuh Januari–Desember 2026, hanya kejadian ~30–40 hari terakhir yang sedang ditampilkan situs BNPB. Untuk arsip historis penuh, gunakan tombol "Isi Formulir Permohonan Data" yang muncul di halaman sumber.
