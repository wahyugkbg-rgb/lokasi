Pengambil Data ArcGIS (Feature Server)

⛔ Peringatan: Browser memblokir fetch dari domain berbeda (CORS). File ini tidak akan berhasil jika dibuka di browser biasa. Untuk mencobanya, buka DevTools (F12) > Console pada halaman BNPB yang sudah Anda login, lalu copy-paste logika JavaScript di dalamnya.
Cara menemukan Endpoint:
1. Buka halaman Data Bencana di BNPB.
2. Tekan F12, buka tab Network, filter dengan kata "query" atau "FeatureServer".
3. Klik permintaan REST API tersebut, dan salin URL-nya (yang biasanya berakhir dengan /FeatureServer/0/query).
4. Masukkan URL tersebut di kotak di bawah, lalu klik "Ambil Data".
